# Focus the Dashboard and standardize SmallBiz colours

## Dashboard
- Remove the three duplicated action cards.
- Keep the personalized welcome and place the primary active goal directly below it.
- Build a prominent active-goal panel using live goal data: name, category, values, percentage, progress, target date, status, update action, and goal-page link.
- Show a clear empty state linking to Goals & Tracking when no active goal exists.
- Add up to three compact additional goals below the main workspace, with a link to all goals.
- Keep Recent Activity compact on the right and place a short, practical business-relevant tip beneath it.

## Product colour system
- Replace the runtime business-brand colouring of the software interface with a fixed neutral charcoal, white, slate, and professional blue system.
- Apply consistent semantic colours for backgrounds, text, borders, controls, progress, success, warning, and errors across all existing pages.
- Give the desktop sidebar a restrained dark charcoal treatment with muted labels and a subtle blue active state.
- Keep business brand colours limited to promotional outputs and brand controls, including generated posters.

## Validation
- Check the signed-in Dashboard at desktop and mobile widths.
- Confirm goal updates and navigation still work, and resolve any build or runtime errors.

## Technical details
- Preserve all routes, authentication, data queries, and existing page functionality.
- Update shared semantic tokens and reusable controls rather than adding per-page colour overrides.
- Keep the existing dashboard goal update dialog and shared Goals & Tracking data source.
